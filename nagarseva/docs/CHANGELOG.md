# Changelog

## 0.3.0 — 2026-10-11 — Public integrations

- Added a dated source catalog and multilingual source library for PMAY-U 2.0, CPHEEO, Census, SRA, BMC, IMD, OpenStreetMap and Open-Meteo.
- Integrated actual geographic tiles with visible contributor attribution, schematic fallback and configurable OSM-derived tile URL.
- Added a live seven-day area forecast, persistent cache, provider retry backoff, explicit stale/unavailable states and source-preserving JSON export.
- Send only approximate area coordinates to the weather provider; forecasts do not affect field evidence, assurance or priority.
- Added published service benchmark references with measurement compatibility notes; existing project commitments remain locally approved records.
- Added resident handoffs to applicable official portals and retained Census data as a reference because reproduction permission is required.
- Rechecked PMAY-U 2.0 screening against the official FAQ and updated its review date.

## 2026-10-11 — Layout and completion review

- Fixed optimizer label/value collisions, allocation comparison collisions, map caption/legend overlap, and landing card overlap.
- Added wrapping and spacing across desktop, tablet and 320px layouts in English, Hindi and Marathi, including expanded forms and dark mode.
- Rendered all valid map locations with a canvas renderer, fitted their bounds, and added filters for imported cities and unassessed locations.
- Read model cards from saved metric artifacts and displayed the cost model's measured limitations.
- Removed a model confidence value after an officer changes its category and retained the reviewed category, department and deadline in history.
- Separated usability completion/timing samples from classification trials; failed tasks do not produce claimed time savings.
- Completed pilot outcome cards, submission feedback and service-compatible commitment inputs.
- Added safe temporary storage when browser persistence is blocked, with a visible notice and working private receipt download.
- Added browser checks for observations, reviews, evaluations, commitments, imports and blocked storage, plus text collision audits across page states.
