# Small pilot protocol

Use one licensed, approved ward/project location. Record source, licence, import approver and permission. Do not reinterpret the schematic MMR illustration as an actual settlement boundary.

1. Invite a few residents and a municipal/NGO worker to evaluate the workflow. Explain what will be recorded and obtain permission; use anonymous participant references.
2. Independently observe one service with its unit and date. Record measurement method, limitations, evidence link and the approved service commitment. Separate reported, resident-confirmed and field-reviewed evidence.
3. Ask each participant to perform an equivalent task in the existing process and in NagarSeva. Counterbalance order where practical. Record timings, completion and observed problems. Do not pair unrelated tasks or mix seconds and minutes.
4. Write multilingual complaint examples independently of the synthetic training templates. Establish expected categories before inspecting model predictions. Record both categories and report language-specific sample sizes and errors.
5. Demonstrate assignment, sourced after-repair evidence and resident confirmation. An actual service improvement needs an actual intervention; simulated repairs must remain demo records.
6. Export evidence, document user feedback and record the product changes it caused. Report exploratory findings and limits. Seek a larger independently reviewed evaluation before claiming policy effectiveness or citywide savings.

## Suggested evidence table

| Evidence | Record |
| --- | --- |
| Location | Source URL, licence, date, approving role |
| Service | Before/after value and unit, timestamps, measurement method, evidence, commitment source |
| User task | Anonymous reference, task, language, baseline/app seconds, completion, feedback |
| Complaint model | Independent expected label, prediction, language, errors and sample size |
| Outcome | Assigned reports, dated interventions, resident-confirmed closures, disputes, overdue reports |

The application calculates exploratory metrics from supplied records. It does not independently validate the truth of a visit, quote, consent or licence.
