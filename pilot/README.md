# UrbanSaarthi pilot preparation

Prepared 18 October 2026. **Prepared materials are not a completed pilot.** No agency, resident or vendor has been contacted by this project. The immediate proposed decision is which water-service inspection to undertake next in one agreed M-East cluster, and what evidence supports closing a related work.

## Proposed ownership

Prospective sponsor: **Brihanmumbai Municipal Corporation, Assistant Commissioner, M-East ward**. Proposed water-domain review owner: **Assistant Engineer (Water Works), M-East**, with the actual asset operator. The current [ward department list](https://portal.mcgm.gov.in/irj/portal/anonymous/qlacmeward) lists this office. The [published departmental manual](https://portal.mcgm.gov.in/irj/go/km/docs/documents/MCGM%20Department%20List/Wards/Assistant%20Commissioner%20%28MEast-Ward%29/RTI%20Manuals/Model%20RTI%2017%20Manual%20Assistant%20Engineer%20%28Water%20Works%29.pdf) describes ward-level water responsibilities and administrative control. Both accessed 18 October 2026. The manual is undated in this review and does not confirm current incumbents or an authority to adopt this software. Obtain the current delegation and asset contract before an operational trial.

Use the [request draft](adoption_request.md) through the office's normal administrative route. Do not use emergency/control-room lines to solicit a project. A specific office is identified, but a named participating official, permission, current records and a recurring payer remain **unconfirmed**.

## Deliverables and acceptance gates

| Gate | Required evidence | Current state |
|---|---|---|
| Task owner | Written agreement naming review owner and actual maintenance operator | Missing |
| Data permission | Approved geometry, public-asset IDs, source dates and permitted uses | Missing for settlements/services; see acquired public context separately |
| Baseline | Existing review procedure and independent assessments recorded before seeing rankings | Missing; template prepared |
| Cost basis | Itemised current quotations or approved schedule references, taxes and exclusions | Missing; quotation template prepared |
| Trial | Up to 20 agreed public water assets, three review rounds; record unsuccessful visits | Proposed target only |
| Continue/stop | Evidence quality and effort compared with current process, approved O&M payer | Decision pending |

The five demonstration clusters are never substitutes for these field records. No present household-service coverage, beneficiary count, housing shortage or local deprivation prevalence can be derived from the acquired map context.
