# Delivery and validation boundary

The current pack contains UrbanSaarthi application drafts, a six-slide deck based on the acquired official template, its PDF copy, scripts, judge answers, an editable illustrative review-trial budget and a prepared pilot/independent-baseline kit. Personal details remain omitted. No submission or office outreach is recorded.

`submission/scripts/prepare_pack.py` checks draft word budgets, required files, local links, six native slides with a comparison table and notes, budget arithmetic, archive integrity and file hashes. Presentation layout/import/render checks are recorded separately in [presentation validation](presentation_validation.json). Neither check is a PowerPoint execution, authenticated portal acceptance or field validation.

Application correctness is recorded in [CI outcomes](../integration/ci-validation.json) and [actual Chromium checks](../integration/urban-validation.json). The report names its tested commit; a newer documentation commit is not itself a new test run. Public-source acquisitions and failures have dated receipts. Current agency adoption, field accuracy, user savings, household benefit, quotations and recurring finance remain unverified.
